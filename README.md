## 這是**WordCards**背單字神器：
* **可播放單字音檔**
* **可自動循環播放音檔和複習每個單字**
* **可編輯單字卡內容**<br><br>

## **功能介紹**：
1. **自動循環播放**：按下右側Play按鈕即可執行 。
2. **手動重複播放單字**：點擊鍵盤Space，可**重複播放音檔**。
3. **手動跳下一個單字**：點擊鍵盤Enter，可**跳至下一個單字**。
4. **編輯單字**：連續點擊兩次左側想編輯的單字，會跳出**編輯單字視窗**。
5. **結束程式的二次確認**：按下 **[結束程式]** 按鈕後，會需要再一次確認退出。
